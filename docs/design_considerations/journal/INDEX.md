# Design Considerations Journal

## Purpose

This directory is a condensed, AI-readable journal of the project's intellectual development.

The original files in `docs/design_considerations/` remain the primary research archive.
This `journal/` directory is a secondary layer for:
- timeline reconstruction
- consolidation of repeated ideas
- clearer reading order
- tracking how hypotheses changed over time
- preserving provenance back to source DCs

## Reader Model

The primary reader is likely an AI system that needs:
- compressed historical context
- explicit status markers
- clear distinction between observation and interpretation
- links back to source documents
- a readable map of conceptual evolution

## Editorial Rules

- Do not replace or overwrite the original DCs.
- Treat original DCs as lab notebooks and primary evidence.
- Treat journal files as curated syntheses.
- Preserve failed paths, revised theories, and superseded interpretations.
- Distinguish clearly between:
  - Observation
  - Hypothesis
  - Validation
  - Current interpretation
- Every journal entry should cite source DCs.
- Prefer chronological narrative over topic fragmentation.
- Prefer explicit uncertainty over retrospective certainty.

## Recommended Reading Order

1. `ERAS.md`
2. `00_project_orientation.md`
3. Era journals in numeric order
4. Topic syntheses (to be added later)
