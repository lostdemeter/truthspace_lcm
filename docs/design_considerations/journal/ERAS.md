# Era Map

## Goal

This file defines the first-pass periodization of the design considerations archive.
These eras are editorial groupings for readability and consolidation. They are not claims of strict discontinuity.

## Era 1: Early TruthSpace and Semantic Geometry

- Rough DC range: `001-040`
- Core themes:
  - emergent geometry
  - semantic structure
  - concept disambiguation
  - knowledge ingestion
  - overlap and composition
- Narrative role:
  - the project begins by asking whether meaning can be navigated geometrically at all

## Era 2: φ Navigation and Lattice Period

- Rough DC range: `041-099`
- Core themes:
  - phi dials
  - holography
  - emergent phi geometry
  - geodesics
  - absolute lattice intuition
- Narrative role:
  - geometry becomes more structured and starts acquiring specific mathematical language

## Era 3: φ Lattice and Model Replacement

- Rough DC range: `100-176`
- Core themes:
  - phi arithmetic
  - adapters
  - lattice weights
  - zeta-aligned architecture
  - navigation vs inference
  - autoregression reframed
- Narrative role:
  - the project begins asking whether learned computation can be directly replaced by geometric computation

## Era 4: Reverse Engineering and Model Boundaries

- Rough DC range: `177-244`
- Core themes:
  - disentanglement
  - bottlenecks
  - spectrometers
  - encoder studies
  - model replacement limits
  - analytic vs irreducible learned structure
- Narrative role:
  - the project becomes more empirical, with sharper boundaries between what can and cannot be replaced analytically

## Era 5: Gate Physics and Machine Anatomy

- Rough DC range: `245-266`
- Core themes:
  - gate field
  - 4-state dimension
  - polarization
  - compound machine
  - targeter/filter/atlas
- Narrative role:
  - the transformer is described as a physical machine with zones, media, and operating principles

## Era 6: Zeta Synthesis and Shape Ontology

- Rough DC range: `271-289`
- Core themes:
  - expanding tensor
  - Riemann-Siegel correspondence
  - path integral
  - full loop
  - ShapeSpace
  - geometric engine
  - shape composition
- Narrative role:
  - previous reverse engineering work is reinterpreted through zeta, holography, and shape-based storage

## Era 7: TruthSpace Return and Platonic Map

- Rough DC range: `290-299`
- Core themes:
  - concept census
  - vocabulary partitioning
  - sieve and zero-hunting
  - layers as backpropagation
  - TruthSpace is real
  - platonic ideal discovery roadmap
- Narrative role:
  - the project returns to concept ontology with stronger mechanistic machinery and attempts a global map

## Notes

- Era boundaries may be revised as consolidation proceeds.
- Actual discovery order should use document timestamps, internal citations, and experiment dependencies in addition to DC numbering.
- A later `inventory.md` should track each source file with tags and era membership.
